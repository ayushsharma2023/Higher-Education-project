# Advance Higher Education ML Project

A simple education ML app using Python, Flask, and a frontend built with HTML/CSS/JavaScript.

## Run the project

1. Open PowerShell in this folder:
   ```powershell
   cd "c:\Users\ayush\OneDrive\Desktop\Advance_higher_education_project"
   ```
2. Activate the virtual environment:
   ```powershell
   .\venv\Scripts\Activate.ps1
   ```
3. Install dependencies:
   ```powershell
   python -m pip install -r requirements.txt
   ```
4. Start the app:
   ```powershell
   python app.py
   ```
5. Open this in your browser:
   ```text
   http://127.0.0.1:5000
   ```
